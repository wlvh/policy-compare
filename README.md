# 保单 PDF 比较工具：使用说明

选择旧版和新版 PDF，查看文字、金额和条款变化，并点击变化回到原文核对。**当前是开发试用版，仍需人工核对，不能直接作为完整审单结论。**

## 下载并打开

电脑需要 **Node.js 24**，浏览器建议使用 Chrome。两版界面相同，先下载 PDF.js 版即可：

- [下载 PDF.js 运行包](https://github.com/wlvh/policy-compare/releases/download/review-20261026-fixes/policy-compare-pdfjs.tar.gz)
- [下载 MuPDF 运行包](https://github.com/wlvh/policy-compare/releases/download/review-20261026-fixes/policy-compare-mupdf.tar.gz)

解压，在解压后的文件夹打开终端，输入：

```sh
node server.mjs
```

用浏览器打开 **http://127.0.0.1:8080/**。使用期间保持终端开启，结束时按 Ctrl+C。不要直接双击里面的 HTML 文件。首次运行不用安装源码依赖。

仓库和下载页目前是私有的，接收者需要仓库读取权限，并登录 GitHub。

## 怎么使用

1. 在「01 基准版」选择旧 PDF，在「02 待审版」选择新 PDF。
2. 首次体验可选运行包内 `samples/before.pdf` 和 `samples/after.pdf`，左旧右新。
3. 点「开始比较」。左侧显示变化，右侧显示两份原文。
4. 点击变化卡片，核对两边高亮：红色为旧文字，绿色为新文字。
5. 搜索框用于找原文，分类下拉框用于筛选变化。检查结束前回到「全部变化」，也要查看黄色的「需要核验的范围」。
6. 要保留结果，点「导出 JSON」；结束时点「关闭任务」。

每份最多 **100 页、30 MiB**。有密码的文件填写密码。PDF 在浏览器本地处理，不上传；目前不识别扫描图片中的文字。

## 结果怎么看

| 提示 | 含义 |
|---|---|
| 比较完成 | 程序在可提取文字范围内完成比较，仍需核对变化是否正确 |
| 未完全覆盖（黄色） | 有内容没读完整，或旧、新文字没有可靠对应；查看待核验范围，不能只看变化清单 |
| 处理失败 | 本次未正常完成，查看错误信息并检查文件 |

**卡片多不等于重要变化多，没有卡片也不一定代表没有变化。** 同名公司、表格、跨页内容和黄色提示需要回到原文确认。

较复杂的两对合成续保样本在 [测试文件目录](https://github.com/jiehuan/falcon-mini/tree/0eef67dd6cbe477ab625885220686c674640fb88/testdata/renewal)。进入一个子目录，下载 `left.pdf`（旧）和 `right.pdf`（新）；`changes.md` 是作者记录的变化答案。当前两版运行这两对文件都会显示黄色提示，尚未完成全部变化的逐项验收。

## 当前问题和使用注意

- **表格关联还不完善。** 程序可能读到公司名和数字，却没认出它们属于同一行。例如航空样本第 8 页，HPX 的份额 12.5%→10.0% 尚未完整列成一条变化。
- **部分页码会误列为重要变化。** 商务航空样本存在这种情况，需要人工排除。
- **黄色提示较笼统。** 一组可能涉及多个位置，点击后先跳到一处；跨页内容还要翻页检查。

目前主要难点是通用地识别表格行列，正确连接「公司—数字」，并减少页码、水印干扰。这些能力尚未完成。

反馈时记下：**使用哪一版、哪对文件、双方页码、你认为正确的变化、实际显示和截图**。请按资料授权范围分享原文、截图和导出结果。

原测试和已修问题见 [验收报告](docs/acceptance-report.md)。当前仍有完整内存、普通电脑和真实业务文档验收未完成；本次提供的是可运行试用版本。
