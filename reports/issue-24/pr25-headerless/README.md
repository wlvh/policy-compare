## 局部处理

矩形首行保留为候选列名，不直接认定为表头。需要传播非恒等列置换时：

- 候选列置换须在后续行得到非平凡支持，即移位列的值确实出现在对应的新列，而不是借用未移动列的相同内容作为证据。
- 如果该解释会把原位保持不变的单元格改写为确定变化，则不传播该置换。
- 同一局部行组的验证结果缓存，单元格候选配对和输出阶段共用；不在配对阶段用未经支持的列名进行交叉对应。
- 恒等列顺序继续按实际列位置比较；未确认首行角色时，仍可以表达首行字面单元格自身的位置变化。界面将其称为“Same cell text, changed position”，不自动称为表头变化。

没有添加隐藏的 headerless 输入标记、数字/年份白名单、业务词表或文档 profile。没有增加 PDF、范围警告或算法未决来代替 A 行变化。

实际补修结果见 `after-scenario.json.gz`、`after-scenario.log`：A 行两个数值各有来源正确的位置变化，B 行没有文字编辑，coverage 和 unresolved 均为零。原有数字表头整列换序和无表头普通数值修改两个对照继续通过。
