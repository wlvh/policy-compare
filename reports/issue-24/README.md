## 交付行为与边界

原文先按真实提取行、同行几何信息和字符来源恢复比较单元。同一基线上的标签/值片段可以合并；近邻续行和最多八个相邻单元用于识别文字重分块。匹配使用原文及来源映射；规范化不抹掉原始拼写、连字或空白变化。

同行 `Label: value` 的标签是输入文字，没有字段白名单。跨行标签值继续比较文字，不自动认定字段绑定。简单矩形表格不固定列数或键位置，表头有无均有测试；表头文字及列位置支持对应。列换序时逐列核对原文，不以单元格集合相同判定无变化。全大写、旋转、缩进和唯一数字不生成业务身份；数值全局唯一也不能覆盖稳定 A/B 区块中的局部关系。

所有出现位置先分别对应。相同修改在界面折叠时，导出仍保留每条原始比较记录及其自己的编辑操作。仅确定次数差时，摘要显示全部来源和次数，明确具体增删实例未确定；摘要默认可见，示例定位使用中性标记，不涂成已确定的新增/删除位置。相同总次数或金额集合不能抵消局部交换。

歧义只保留在有竞争对应的局部范围，相关旧新原文及实际变化仍可见，明确的其他修改继续比较。结果不输出航空业务归属，不把匹配分数称为正确概率。界面用普通英文说明对应依据。

英语范围检查是轻量的输入检查：连续非拉丁字母、以及缺少普通英语词语线索的较长拉丁字母语句会给出具体行范围提示。重音名称、组合字符、连字、孤立数学/单位符号有正例。该检查不能可靠识别所有语言；罕见英语措辞也可能被标为范围未确认。检测到的范围缺口使结果为 `partial`，原文仍继续比较，不能借提示放行一个未发现的编辑。

跨页重复表格文字、相邻表格行的不同单元格边界有具体来源提示，不宣称已恢复跨页、合并格或多行单元格身份。简单表格以外的结构不保证完整恢复，但仍要求原文变化可审查。沿用提取器、来源定位、工作预算和取消机制；预算或词级差异工作量超限会给出局部未完成证据。

输入、生成源及 SHA-256 在首次比较前固定于 `validation/issue-24/pdfs/manifest.json`；三对预期来自明确原文编辑。正文和两列表由 ReportLab 4.4.9 生成；多列清单由独立 HTML 经 Chromium 打印生成，文件自身 Producer 为 `Skia/PDF m157`。两种制作来源不是同一文件重复导出。六份 PDF 均经过页面渲染检查。

首次浏览器核验中，MuPDF 三对通过；PDF.js 在正文样本处因验收工具拿 Node 提取坐标校验浏览器坐标而失败，后两对该轮未执行。调查证实标准字体在 Node 与浏览器使用的字体外框高度不同，字符 ID、原文和标量范围相同。它不是 Rust 错归属证据，也不能仅因文字相同便豁免来源校验。

修正后的浏览器验收在输入送入 Rust 之前捕获实际 `meta/page`，先核对结果的输入快照哈希，再验证每个来源、实际页面行及词级高亮。`accepted-*/*-actual.json.gz` 保存实际输入和导出结果。三对样本在诊断后均按开发回归管理，没有替换首次记录，也不把最终候选的回归结果重新称为未见样本验证。本轮按 Issue 约定完成首次验证及必要回归，没有循环增加三对新样本。

## 旧新差异的处置

最终 64 次旧新对照分类：**展示差异 64、新版修复 0、真实退步 0、尚不能裁决 0**。这是这 32 对受控样本的逐例结论，不是通用正确率或全部历史审计结论。

旧版正确的聚合展示也按自己的全部出现来源验证，不能仅因旧卡只展示代表项的编辑操作就判旧版失败。发生了可核验的原文变化且每次来源明确，允许保留旧版聚合与新版逐次记录这两种表示。最终对照没有把“更加保守”另立类别或免除真实退步。

展示差异包括航空字段/行键不再输出、变化按原文和列组织、旧业务分类不再推断、计数与逐次修改分别展示。R24 等复杂结构的具体范围提示不抵消其原文事件要求；检出、来源、重复变化和反错配仍独立通过。开发初期的不必要未决、地址值全局串配和短旋转词局部对应问题已在受控回归中处理，首次开发对照保留于 `controlled-first.json`。另补的裸金额 A/B 交换反例及修复前失败保留于 `bare-values-before.log`。

## 复现

在已安装项目固定工具链和依赖的仓库根目录执行。若系统 Node 不是 24，可使用本仓库的 `bash scripts/pnpm-local.sh` 前缀。

```sh
bash scripts/pnpm-local.sh build:core
bash scripts/pnpm-local.sh verify:core
bash scripts/pnpm-local.sh exec tsx scripts/issue24-compare.ts
bash scripts/pnpm-local.sh test:rules:mupdf
bash scripts/pnpm-local.sh test:rules:pdfjs
bash scripts/pnpm-local.sh build:mupdf
bash scripts/pnpm-local.sh build:pdfjs
bash scripts/pnpm-local.sh exec tsx scripts/issue24-pdfs.ts
POLICY_BROWSER_CHANNEL=bundled bash scripts/pnpm-local.sh test:browser:mupdf tests/browser/issue24.spec.ts tests/browser/rules.spec.ts tests/browser/rust-core.spec.ts
POLICY_BROWSER_CHANNEL=bundled bash scripts/pnpm-local.sh test:browser:pdfjs tests/browser/issue24.spec.ts tests/browser/rules.spec.ts tests/browser/rust-core.spec.ts
```

`--first` 模式会拒绝覆盖已存在的首次报告；生成器也会拒绝重建已冻结输入。默认 PDF 命令仅生成开发回归。上述命令不部署，也不改变系统代理、默认工具链或运行账户。
