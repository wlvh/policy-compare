## 有限补修

1. 表格行的对应保留连续行组之前的局部原文。双方都保留的不同区块文本约束对应，重复表头不再覆盖区块差别；表格候选、精确对应和后续相似对应共用这个约束。已有标签值行继续使用其原有的字面标签上下文，没有恢复航空身份。
2. 表头从单页连续、相同单元格数的行列关系中取得，不以数字、年份或特定字段名准入。简单矩形表格按单元格从左到右的次序对应列，文字左/右/居中对齐不改变其列。跨页、合并格等原有限制不扩张。
3. 逐单元格输出保留整行移动信息。原文和位置完全相同则不报告移动；位置确有变化的整表移动仍可显示带来源的移动，不靠把所有单元格的 moved 固定为 false 来消除输出。
4. 评分器按独立预期执行五条原文/移动控制：`no_content_differences`、`no_false_clause_moves`、`no_false_text_added_or_removed`、`no_false_row_additions_or_deletions`、`moved_clause_has_no_internal_word_edits`。另检查 Moved 是否反而具有完全相同的两侧位置，并对真正的配对卡检查来源记录归属。

计数摘要只列来源和数量，不声明列表中每两个实例可靠对应，因此不按普通配对卡强加记录身份。加强评分的首稿曾错误地把 R13 的计数摘要当作配对；原始首稿结果保留在 `strengthened-before/`，最终修复前结论使用正确区分这一语义的 `before-rescored.json`，没有把评分器误判算作产品修复。

上述五条控制及已有事件、来源、重复次数检查构成本次重算的明确范围。其余历史不变量逐项列在 `historicalInvariantsNotReplayed`，完整历史维度状态为 `NOT_EVALUATED`，没有计为通过；没有重写整个评分平台，也不把当前 source-scope PASS 解释为所有历史业务身份、分类或完整性不变量均已通过。
