## 实际行为

- 已标明类型的两类结构观察默认收起；同一原因解释一次，按基准/修订、页和区域列出全部原始记录。
- 点击来源按原始 region 定位，并用 Review area 标明具体区域；窄屏显式导航也有回归。已知结构观察不会在默认页面上全部涂成漏比区域。
- 页面失败、图像/编码等覆盖问题和预算中止保持醒目摘要。未标明类型的 unsupported_structure 仍归覆盖检查，不按文字猜测或自动弱化。
- 对应争议也出现在与其原文字符相交的变化卡附近；同页其他变化不借用这条争议。
- 导出中的 coverage、unresolved、status 原样保留，所有来源可展开。解析错误的具体说明在详情中直接可读。
