## 受邀者任务单

邀请 5–10 位接近真实使用场景的人，至少包含普通配置 Windows、Chrome 与 Edge。使用编号 U01–U10 记录，不在仓库保存姓名、联系方式、真实 PDF 或含原文的反馈。

用户可自行转发公开网址并收集反馈，受邀者名单不构成部署前提。当前没有代发邀请，参与者及真实业务样本数均为 0。

观察人先不提示答案。受邀者依次执行：

1. 首次打开网址，不接受操作指导，独立完成内置金额样例的比较。
2. 说明找到了什么金额变化，打开原文证明，并尝试搜索和导出。
3. 运行扫描图片样例，用自己的话说明哪些内容尚未比较。
4. 使用获准的较长或密集表格样本，记录等待时是否知道任务在做什么，审阅与滚动是否卡顿。
5. 在处理中取消，再开始比较；关闭任务后重新选择样本。若没有实际取消，不计通过。

分开记录三段时间：进入应用路径到引擎就绪；选择文件并开始到结果可审阅；定位、搜索、滚动与审阅过程。记录网络、操作系统、CPU、内存、浏览器版本及首次/重复访问。未开始、失败和中途放弃均保留，组织者主动向每位受邀者询问结果。

反馈只需“我做了什么；我预期看到什么；实际发生什么”，以及下载诊断。比较错误另附样本编号与双方页码。诊断只有版本、引擎、浏览器、阶段和错误代码；比较结果 JSON 包含原文，不按同一种分享规则处理。
