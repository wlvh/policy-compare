## 必须保留的验收边界

工程综合与业务试点没有宣布全部通过。完整内存统计无法覆盖采集前退出的短寿命浏览器子进程；普通 16 GiB/实际目标设备、获准真实样本和独立封存留出尚缺。本机 Docker 无响应的旧 BLOCKED 记录保留；本 PR 的 Linux 容器 CI 是新的补充证据，以实际运行结果为准。CI 绿色不能自动解除其他缺口。
